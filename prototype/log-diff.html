When you click a commit, the viewer below the list splits in two:

  • Top: the commit header as today: hash, labels, parents, message. It sizes to its content.
  • Bottom: the diff, git show --format= -U3 <sha>. One sticky header per file with its +/− counts. Added lines green, removed lines red, context dimmed. It takes the remaining height and scrolls.

Click the other commits to compare:

  • The Parting of the Ways (amended): Ninth → Tenth Doctor, plus the Bad Wolf line.
  • Rose: the first commit, so the whole file is new (all +).
  • Journey's End: a merge. Plain git show shows nothing for a clean merge. The mockup shows the diff against the first parent (--first-parent), which is "what the merge brought into prime-timeline".
