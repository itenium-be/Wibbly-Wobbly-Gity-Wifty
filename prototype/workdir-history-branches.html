HISTORY WITH BRANCHES

The same one-line list, with a lane gutter on the left, like git log --oneline --graph but drawn as lines instead of ASCII.

  • Each branch gets a lane colour, and its label uses that same colour, so fathers-day (orange) obviously belongs to the orange lane.
  • The gold dot is HEAD. Merge commits are a ringed dot where two lanes join.
  • HEAD / --all toggle above the list: reaper is not merged into main, so it only shows under --all.
  • Commits are sorted newest first (--date-order), so the lanes interleave the way they happened.

The ASCII this replaces:

*   9391028 (HEAD -> main) Merge branch 'fathers-day'
| * 77ab1e0 (reaper) Reapers appear
|/
| * c0ffee1 (fathers-day) Rose saves Pete
* | 5d3e2a1 Add Gallifrey
* | 338d796 (tag: s01) Add companions list
| * a913f93 Pete lives
|/
* 570570a Add TARDIS.md

The panel version puts fathers-day and reaper in separate lanes. The ASCII above squeezes them into the same column.
